## 一、项目背景

在自动化产线中，机械手需要从 6 行 7 列的棋盘格料盘中逐一抓取零件。视觉系统会给出料盘上剩余零件（或空格子）的乱序二维坐标。机械手需要按照 **“左上角起步、逐行往返（蛇形）”** 的顺序，以 **最短路径（不交叉、不打结）** 完成遍历抓取。

在探索过程中，解决了三个核心难点：
1. **乱序点如何排序**：仅有坐标、无行列号时，如何还原蛇形路径。
2. **算法性能与形态**：如何保证路径既短又符合蛇形，且无交叉打结。
3. **工程化落地**：如何用 Python 做交互界面，和 C# 做高性能算法 DLL，实现跨语言混合编程。

## 二、算法演进

我们一共实现并对比了三种算法：

### 1. 蛇形 TSP 算法（Snake TSP）
- **核心思想**：按 Y 坐标自适应分行（基于相邻 Y 间隙的中位数），每行内部按照 X 排序（左到右/右到左交替），再通过“就近选择行起点”连成蛇形。
- **特点**：强制保持“逐行往返”形态，适合料盘扫描。但若用全局 2-opt 优化，可能会破坏蛇形结构。

### 2. 自由 TSP 算法（Free TSP）
- **核心思想**：不关心行结构。用**最近邻（Nearest Neighbor）**从第一个点贪心构建初始路径，再用 **2-opt** 局部反转消除交叉，直到无法缩短。
- **特点**：总长度更短，但走向是自由巡游的，不符合料盘扫描需求。

### 3. 混合蛇形 TSP 算法（Hybrid Snake TSP）
- **核心思想**：先分行；每行内部用最近邻+2-opt 求行内局部最优；行与行之间用**动态规划（DP）**选择“正序/反序”，保证行间连接总长最短；最后再跑一次全局 2-opt 微调。
- **特点**：兼顾了严格的蛇形走向和最短路径。

## 三、工程落地

为了提升界面交互效率并实现跨程序语言算法，我们确定了 **Python (Pygame) + C# (DLL)** 的架构：

### C# 实现算法核心
- 封装了 `TspPathSorter` 和 `SnakePathSorter` 两个类库。
- 引入 `PointSet` 类做数据封装，对外提供 `GetX(i)` 和 `GetY(i)`，规避跨语言元组解析的麻烦。
- 输入输出统一为 `double[n, 2]` 二维数组。

### Python 可视化与交互
- 使用 `pythonnet` (`clr`) 加载 DLL。
- Pygame 提供棋盘绘制、鼠标拖拽点选、实时蛇形连线及交叉数统计。

### 踩过的坑与避坑指南
- **IDE 黄线**：`Import "System" could not be resolved` 只是 IDE 静态检查的问题，只要终端能跑就无需理会。
- **包冲突**：必须卸载无关的 `clr` 包，安装 `pythonnet`。
- **命名冲突**：若本地有与命名空间同名的文件夹，会导致 `ImportError`。改为 `namespace TspSorterLib` 可解决。
- **作用域陷阱**：Pygame 窗口 `VIDEORESIZE` 重新赋值 `screen` 时，必须在 `main()` 里加 `global screen`，否则报 `UnboundLocalError`。
- **旧 DLL 缓存**：改了 C# 代码一定要重新编译，通过终端是否有 `[C#] Sort called` 日志来确认调用成功。

## 四、适用场景

- **料盘扫描 / 机械臂抓取**：选 **蛇形版 / 混合版**，必须保证逐行、不打结。
- **激光打标 / 巡游巡检**：选 **自由 TSP 版**，不限制顺序，纯求最短。
- **接口调用**：优先使用 `SortToPointSet` 接口，数据结构清晰，跨语言调用更稳定。

## 五、关于2-优化

**2-opt** 是解决路径规划（特别是旅行商问题 TSP）中经典、常用的局部搜索优化算法。它的核心思想非常直观：**消除路径中的“交叉”**。

### 1. 为什么需要 2-opt？
在平面上，如果你要依次经过 A → B → C → D 四个点：
- 如果线是 `A → B → C → D`，且线段 `AB` 和 `CD` 交叉了，那这条路径绝对绕远了。
- 只要把中间断开，换成 `A → C → B → D`，线就不交叉了，而且**总长度必定变短**（三角形两边之和大于第三边）。

### 2. 算法步骤
假设路径序列：`P0, P1, P2, P3, P4, P5, P6`
1. **找两条不相邻的边**：如选中边 `(P1, P2)` 和 `(P4, P5)`。
2. **计算长度**：
   - 旧连接：`P1 → P2` + `P4 → P5`。
   - 新连接：`P1 → P4` + `P2 → P5`。
3. **如果变短，就翻转**：若新 < 旧，说明交叉了，把中间段反转（`P1, P4, P3, P2, P5`）。
4. **循环迭代**：直到无法缩短为止，得到无交叉平滑路径。

### 3. 为什么叫 "2-opt"？
因为它通过删除**两条边**，重新连接 4 个端点产生新路径。这是一种 2-交换（2-exchange）操作。

### 4. 项目中的作用
- **“去交叉”神器**：只要无交叉，路径就达到了局部最优。
- **速度快**：平方级复杂度，毫秒级优化 50~100 点。
- **保护结构**：初始蛇形路径无交叉，2-opt 只微调，不破坏逐行结构；而在自由 TSP 中则是消除交叉的主力。
